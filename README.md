# Manual: Super Mario Galaxy 2

## Overview
### What locations get shuffled?
All Power Star and Comet Medals become locations to be checked. Green Stars, 1-Ups, Life Mushrooms, Lumalee Shops, ? Coins, Chance Cubes, + Clocks, and Purple Coins can also be optionally included as locations.

### Which items can be in another player's world?
Stars, letters, and Grand Stars which gate access to the different worlds are always in the item pool. Additionally, the ability to use Mario's movement, power-ups, certain level mechanics can be randomized, as well as access to Prankster Comet missions, both by comet type and by galaxy-specific Comet Medal items.

### What is needed to play this?
A 242 star file is recommended. However, as long as neither of the Grandmaster Galaxy goals are chosen, a 120 star, all Comet Medals file should work just fine. Because this is unmodded, either the Wii or the Switch version will work!

## Items
### Grand Stars
These lock access to the different worlds of the game. One will be given as a starting item, and they do count as Power Stars.

### Movement
Seven of Mario's abilities can be randomized. These are:
 - Spin: Skating is included. Most other actions that involve shaking the remote aren't, but if you're not sure, feel free to ask!
 - Ground Pound: Diving underwater is included.
 - Backflip
 - Sideflip
 - Triple Jump: This includes Double Jump.
 - Wall Jump: Wall sliding is NOT included.
 - Long Jump
   
In addition, Spin and Triple Jump can be optionally split into two Progressive items. These are:
 - Progressive Spin: The first one allow for spinning on the ground and underwater as well as skating, while the second allows for spinning in the air.
 - Progressive Triple Jump: The first allows just Double Jumps, and the second allows Triple Jumps.

### Power-Ups
The randomized power-ups are:
 - Cloud Flower
 - Fire Flower
 - Bee Mushroom
 - Boo Mushroom
 - Spring Mushroom
 - Rock Mushroom
 - Rainbow Star
 - Spin-Drill
 - Yoshi
 - Bulb Berry
 - Blimp Fruit
 - Dash Pepper

Generally, any functionality a power-up has by shaking the remote is not tied to Spin. The main exception is the Cloud Flower.

### Mechanics
There are eight randomized level mechanics. These are:
 - The Star Ball
 - Fluzzard
 - Koopa Shells
 - Cannons
 - Pull Stars
 - Tornadoes
 - Floaty Fluff
 - Bob-ombs (Specifically, Bob-ombs blowing up cages)

### Comets
Depending on the setting, either all comets will be locked behind a single Prankster Comets item, all will be available from the start, or each type will be locked individually. This includes Green Comets.

## Misc. Information
### Deathlink
A death is defined as when Mario or Luigi loses a life to any reason other than a received deathlink. When a deathlink is received, no checks can be collected until Mario or Luigi loses a life.
